# Changelog

Format based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/).

## [Unreleased]


### Changed
- Prompts require every diagram to be a fenced `mermaid` block (no ASCII or box-drawing art) with quoted punctuation labels, so diagrams render in Markdown viewers.

### Added
- Output post-pass that fences Mermaid the model left untagged, tagged `text`/`mmd`, tagged with the diagram keyword (e.g. ```` ```sequenceDiagram ````), or unfenced, as ```` ```mermaid ````. Code fences in real languages are untouched.

## [2.0.0] - 2026-10-21

### Added
- Book mode: an ordered set of chapters (orientation, main flow, subsystems, contributing) plus `INDEX.md`, `FILES.md`, `UNCERTAINTIES.md` and `provenance.json` in `docs/architecture/`.
- Snapshot of the repository per run; excerpts are pasted from it by the tool, and model replies are structured JSON.
- Structural labels on references and import links, with limits stated in the output.
- Recoverable publishing, a generation cache, plan reuse, and private state in `docs/.repo-summarize/`.
- Backend sandboxing (`sandbox-exec` on macOS, `bwrap` on Linux if installed), a probe on backend change, and `--unsafe-backend`.
- Best-effort secret skipping and line-preserving redaction.
- `--estimate`, `--max-calls`, `--replan`, `--clean`; `REPO_SUMMARIZE_TIMEOUT`, `REPO_SUMMARIZE_PASS_ENV`, `REPO_SUMMARIZE_CACHE_NAMESPACE`.
- Exit codes 3 (aborted), 4 (capped) and 5 (backend unsafe).

### Changed
- Rewritten as a single-file stdlib Python 3.12+ script run through `uv`.
- Default backend is `agy --disable-slash-commands -p`.
- Tests run with pytest against a stub backend.
- On first publish, files generated by earlier versions in `docs/architecture/` are removed; hand-written files are kept.

### Removed
- The Bash implementation and `tests/smoke.sh`.
- Per-file documents as the default output (planned for v2.1 as `--reference`).
- `--filter` and `--max-files`.

## [1.0.0] - 2026-10-03

First public release, extracted from a private dotfiles repository where it was developed from 2026-09-18.

### Added
- `REPO_SUMMARIZE_CMD` to choose the AI backend (default `agy -p`, no permission-skipping flag).
- `tests/smoke.sh`: offline end-to-end test using a stub backend.
- MIT license and standalone documentation.

### Included from prior development
- Pass 0 scan (no AI): repo map, entry points, heuristic import graph; per-file prompts carry callers and callees.
- Annotated walkthroughs: a comment above every line for files of 150 lines or fewer, per-block explanations above that, with "unknown" over invention.
- Reliability: failed files are logged and skipped, INDEX synthesis failure keeps the old `INDEX.md` and exits non-zero, docs regenerate when the source is newer, prompts are size-guarded, nested source links fixed.
- Progress tracking (`.progress.json`) and `--status`.
- `--dry-run`, `--filter`, `--max-files` (sampled across top-level directories), `--force`, `--open`.
- bash 3.2 compatibility (no associative arrays).
- Comprehensive coverage written to `docs/architecture/` with an AI-synthesised `INDEX.md`.
